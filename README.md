# elijahwherrington.com

Static site for GitHub Pages. No build step needed to deploy: upload these files to the root of the repo.

- `index.html`, `about.html`, `skills.html`, `projects.html` — pages
- `assets/` — shared stylesheet and script
- `img/` — photos, video, brand logos, diagrams
- `CNAME` — keeps the custom domain pointed at GitHub Pages (do not delete)
